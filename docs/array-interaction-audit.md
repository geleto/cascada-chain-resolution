## Finding pass

The previous sequential-equivalence and layout reviews supplied positive controls, particularly private whole-scope publication, observation around an unresolved region, vector status versus presence, and iterative tail selection. The initial test generators had orthogonal-axis and diagnostic gaps. Borrowed backing was selected by `seed % 4 === 0` and deferred splice controls by `seed % 2 === 0`. Therefore a borrowed-backing splice in that generator could never have immediate controls. Splice start and count also came as a pair with one delivery route. The same seeded program ran in one Chain mode, and the conflict matrix tied mode to the case ordinal. A label of `ERR` conflated the source, category, and underlying cause.

The Array generator now chooses backing, control timings and command key timings independently, before replay. It replays the same seed in every Chain mode and all three harness modes. Point reads and final Error collection also compare operation context and exact supplied cause. The full conflict matrix crosses each case with all three policies. The dedicated excluded-index grid covers 12,672 replays across two backings, nine mode pairs, four observer configurations and independent ready, synchronously delivering and deferred controls. It covers every deferred delivery order partitioned between the three intervals after the first splice, after the copy, and after the observers. The 54 historical/repair cases cross two outcomes with nine policy pairs and three deliveries. The two-cause checks enumerate the two independent timings and both deferred orders in the two streaming modes. Eighteen alias cases verify shared identity before an indexed write and separation of precisely the written occurrence afterward.

The excluded-index assertion rejects a scratch cut that removes one fewer element. The first divergence was the early export of `["X", <hole>]` instead of `["X"]`, with the removal width and start ready and the copy count delivered later. An independent scratch change to complete Error collection kept only the first leaf. The two-cause check rejected that single Error in place of the compound. The earlier committed revision also passed the excluded-index and historical grids, so the archived source alone did not calibrate those assertions.
