## Contract-derived sequential oracle

For an all-ready call, first select its receiver at its issued position. Common ownership preparation may precede this selection when mutation or pending receiver selection requires it. The selected category determines which inputs are consumed. Required conversion/export finishes before method-member lookup and invocation. An argument to a ready rejected observation is unused; provisional preparation does not turn unused data into a required wait or failure-collection obligation.

Receiving route cannot change an available identity's category. Ordinary managed receiving prepares fresh structure and preserves an already prepared value's producer. Mutable external property reception first captures detached ready managed data; it must neither admit the mutable source in place nor wait for nested source data. Native receiver-path getters are distinct from managed accessors, which are absent graph placements.

Array structural payloads remain values, including poison and pending values. Required scalar conversion, identity search input and comparator validation have different contracts. Output failure can release successful payloads and copied shells, while required shape, candidate failures and poison collection remain unfinished. A native call's completion, receiver publication and independent returned result have separate completion meanings.

Source access ends after the final required capture/read; managed output assembly can continue from exact versions and source-free records. Retained native causes keep their exact diagnostics and unformatted stacks. Genuine host CallSite receivers and host-retained output are distinct from removable runtime closure bindings. Local closure stops only operation work; a previously installed shared producer still settles/indexes in a live execution. Fatality stops both shared and local resumption and rejects only presently pending public results.
