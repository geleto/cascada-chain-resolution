## Representing an unresolved cut

**Store one shape/control record per unresolved splice.** It refers to the predecessor extent N, relevant start and delete-count roles, and inserted width W. Consume each role at the method’s demand boundary, preserving omission, explicit `undefined` and failure. Use existing placement evidence when obstruction is certain before the exact cause or repair outcome. N can depend on an upstream `concat` classifying an operand as scalar or Array. A pending element in a known one-slot operand adds no width dependency. [Error evidence](../src/error-evidence.js) · [Shape capture](array-layout-implementation-findings.md#shape-captures-have-their-own-versions)

```text
S = normalize(start, N)
D = clip(deleteCount, 0, N − S)        using the call's omission rules
P = predecessor positions, including holes     I = inserted positions
successor = P[0,S)  ++  I[0,W)  ++  P[S+D,N)
removed   = P[S,S+D)
```

A range names a captured source and two boundaries. An open boundary refers to this cut and the relevant endpoint. Both occurrences of S+D use the same S and D. A rear read uses the correlated remainder N−S−D. Distinct argument positions stay independent even if given the same Promise. [Captured control identity](array-method-specification.md#3-unknown-lengths-and-shared-controls)

For an in-range front index q on a healthy representable successor, `q < S` selects `P[q]`. Otherwise `q−S < W` selects `I[q−S]`. The remaining case selects `P[(q−W)+D]`. An unresolved predicate keeps its possible ranges under that **same** S and D. An implementation can intersect a whole window against those guards in one step. It must also consider failure or absence before publishing a point. This representation needs at most three source intervals for one determined splice and contiguous window.

A front index q that can occur uses the singleton window `[q,q+1)`. Give its placement gate the restricted sources so dropping a full-result holder releases everything else that can retire. Structural transfer preserves presence, status, role and producer under the destination’s sparse or densifying rule. If a splice leaves structural Error E at zero, `slice(0,1)` preserves it. Pushing `lookup(0)` from that slot into an empty Array gives its cursor one ordinary item holding E and a clean end. Two positions sharing a source are distinct occurrences, including holes. Spans can encode their multiplicity. Each cursor owns its progress. [Occurrence and status rules](array-method-specification.md#10-sparse-data-occurrence-roles-and-queries)

Keep restricted intervals in source coordinates through their last use. This replaces the private padded sequence that `splicePointInputs` builds to remember offsets. Ready bounds can go straight to native storage. Pending bounds can use the existing Variant B range storage. [Current point capture](../src/array-splice.js#L466) · [Shape and content ownership](array-layout-implementation-findings.md#1-separate-semantic-facts-from-owned-contents)

### Work through a history of edits

- **Determined ranges.** A splice needs a constant number of range boundaries in addition to its explicit insertions. Split and join balanced fixed spans, or stream required physical descriptors in source inspection order when building a native Array. With B fixed spans, a contiguous query can locate its first span in O(log(B+1)) and visit only the spans or output it consumes. Observational splice can skip discarded descriptors. Mutating splice needs the removed range too. [Fixed storage](../src/array-layout.js) · [Direct copy experiment](array-iteration-retrospective.md#captured-ranges-and-slice-history)
- **Unresolved history.** Keep symbolic cuts only while a live question, publication or promised effect can distinguish their outcomes. Compose decided adjacent translations or restrictions, share their indexed ranges between versions, and traverse irreducible cuts iteratively during selection, activation, completion and release. For fixed first/last crops of an unknown length, consecutive cuts on the same side collapse. Alternating tighter cuts can need one origin term per surviving run. Charge that information once across shared captures. Preserve end-relative answers, intermediate flags, capacity loss and independently held versions when shortening a path. [Derivation and measured cases](array-iteration-retrospective.md#captured-ranges-and-slice-history)
- **Repeated historical reads.** Measure both retained-point workloads below and the small-graph control in which H optional writes at index zero all resolve to no effect. For H edits and Q scalar readers, target O((H+Q) log(H+2)) total history/index work across issuance, settlement and release. Apply the same upper bound to peak history/query records. Count consumed input, actual parent-key changes and produced output separately. A cache keyed only by the final version and index still makes different versions walk the same predecessors. ## Decide whether to extend the rewrite

Try `copyWithin` and `fill` through the same range operations, reading overlapping copies from the pre-write source. Remove the duplicate interval mapping in `applyLayoutMethod` and `IntervalSelection.publishSelected` where it describes the same edit. Verify both directions of overlap, signed bounds, sparse or flagged destinations and failed bounds. Follow `[X,X]` made by `copyWithin!` or by repeating a `concat` operand through `toSpliced(s,0,Y)`. Two Unordered cursors each own their credits. Closing one early preserves the other’s two X occurrences and their eventual distinct ranks. A proved self-copy preserves identity. A prescribed write between two occupied positions holding A advances it.
